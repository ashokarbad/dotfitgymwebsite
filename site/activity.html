Activity story

Activity
template.

This is the reusable page every activity, trek, challenge and event uses. Add an entry to content/activities.json, rebuild, and a page like this is generated with its own hero image, description, details, highlights and photo gallery.

How to add one

Six fields.
That is the whole job.

Open content/activities.json, copy the block below into the activities array, fill it in, drop the photos into /images and run python3 build.py.

{
  "id": "sinhagad-trek",
  "title": "Sinhagad Fort Trek",
  "category": "trekking",
  "date": "12 January 2026",
  "location": "Sinhagad, Pune",
  "summary": "One line describing the activity.",
  "image": "images/treks/sinhagad-hero.jpg",
  "details": [
    { "label": "Difficulty", "value": "Moderate" },
    { "label": "Participants", "value": "24" }
  ],
  "highlights": [
    "Sunrise from the top",
    "Breakfast at the summit"
  ],
  "gallery": [
    { "src": "images/treks/sinhagad-01.jpg", "caption": "Setting off at 5 AM" },
    { "src": "images/treks/sinhagad-02.jpg", "caption": "The group at the summit" }
  ]
}

Only fill in what actually happened. Leave out difficulty or participant counts if you do not have them — the page adapts and simply omits the field.

Every activity gets a gallery.

That is the rule. Photos, description, date, location, and a share link carrying the hashtag.
